> **"Restoring the harmony of our oceans through AI-driven intelligence and community action."**

Samudra Sutra is a premium, cinematic waste intelligence platform designed to combat ocean and river pollution. By leveraging cutting-edge AI for waste identification and a gamified community reward system, we transform environmental conservation into a collective, rewarding mission.

---

## ✨ Features

- **🛡️ AI Waste Intelligence**: Real-time identification of pollutants using Google Gemini and TensorFlow.js.
- **🗺️ Cinematic Live Map**: A real-time, interactive visualization of pollution hotspots and cleanup progress.
- **💰 Impact Credits**: Earn rewards and environmental credits for verified cleanup reports.
- **🏆 Global Leaderboard**: Compete with a community of ocean guardians to lead the restoration effort.
- **📱 Responsive UI**: A premium, "cyber-marine" aesthetic optimized for all devices with fluid animations.
- **📊 Real-time Dashboard**: Comprehensive analytics on waste cleaned, credits earned, and community impact.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS (v4)
- **Animations**: Framer Motion
- **Mapping**: Leaflet / React-Leaflet
- **AI/ML**: Google Generative AI (Gemini), TensorFlow.js
- **Backend/Auth**: Firebase (Authentication, Firestore, Hosting)
- **Icons**: Lucide React

## 📦 Installation & Setup

To run Samudra Sutra locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/PRANAVSP30/SAMUDRA_SUTRA.git
   cd SAMUDRA_SUTRA
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up Environment Variables**:
   Create a `.env` file in the root directory and add your API keys:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```
